# Ask the map

Ask about the 30 pilot cases: counts and lists, a case by ID or name, evidence gaps, what each step of the [evidence spectrum](../map/index.md#the-evidence-spectrum) means, or how the pilot was run. You can use the plain names, such as "operational data" or "proven impact", or the protocol codes L1 to L5. Answers are built by code from the [published map data](../map/index.md), codebook, protocol, Purpose and Use Memo and one-pager, and every answer cites its sources.

!!! info "Code-only version (no AI model)"
    This version uses no AI model and no server. The answering code runs in your browser; your questions are not sent to or stored by us. The first question loads a Python runtime (about 10 MB) from the jsDelivr CDN, which takes a few seconds. Answers about the method are given as the most relevant cited passages rather than a written summary.

!!! warning "What the assistant will not do"
    It does not rank cases or portfolios, recommend what to fund, give a new evidence grade, or show restricted material. Evidence levels describe the type of evidence found in public sources, not the quality of a project. Where the two coders differed on country, region, year, blockchain functions or implementation model, the field is blank for the pilot (see the [map's filter-gap note](../map/index.md)).

The assistant passed the frozen 35-question test set in code-only mode on 19 October 2026 (35 of 35; counts checked against independent counts). Version 0.5 (19 October 2026) answers with the plain evidence names, gives the protocol code in brackets, and understands questions in either form; it passed the same test set again (35 of 35).
