# Protocol

The pilot design report (O1) is the protocol. It is not registered. GSR approved v0.1 at Gate 0, and it is posted here as the public protocol. v0.5 is current: it records the Gate 3 fix plan and cost limits, and keeps the approved design otherwise unchanged. Section 13 covers data management for the pilot; Annex A sets out the full-scale research design.
