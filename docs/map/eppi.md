# EPPI-Mapper version

The same data in the Campbell and 3ie style format, built with [EPPI-Mapper](https://eppi.ioe.ac.uk/cms/er4/EPPI-Mapper). It appears here after Gate 4.

<iframe class="eppi-frame" src="eppi-mapper/index.html" title="EPPI-Mapper evidence gap map"></iframe>

??? info "How to update this map"
    1. After a successful build, download `eppi-mapper.json` from the [Data](../data/index.md) page.
    2. Load it at the [EPPI-Mapper site](https://eppimapper.digitalsolutionfoundry.co.za/), with the saved template from `map-config/` once the codebook is frozen.
    3. Download the HTML, rename it `index.html`, and replace `docs/map/eppi-mapper/index.html`.
